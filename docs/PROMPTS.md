# Prompts — The Prep Knight

Prompt templates for use with the Claude squire tab.

---

## Analyze Job Posting

```
Analyze this job posting and tell me:
1. Key required skills
2. Nice-to-haves
3. Red flags
4. Fit score 1-10

Job posting:
[paste here]
```

---

## Cover Letter

```
Write a compelling cover letter for this role. Make it genuine, not generic. Keep it under 300 words.

Company:
Role:
My background:
Job description:
[paste here]
```

## Tailor Resume

```
Tailor the following resume bullet points for this job posting.

```

## Salary Negotiation

```
I received an offer for [Role] at [Company]. The offer is [amount].
Market rate is [range]. Help me write a professional counter-offer email.
```

---

## Cold Outreach

```
Write a short cold LinkedIn message to a [Title] at [Company].
Goal: learn about the team / get a referral.
Keep it under 100 words.
```
